> 日期：2026-09-07 ｜ 模块：生产-生产管理 / PmsProduceOrder

取消独立「派工」页。在**新增 / 修改生产单**时一并填写领料信息、调整原材料领用数量，**保存生产单的同时同步生成领料单（LLD）**，不再单独派工。

## 关键设计
1. **整单重建**：保存时先按 `FProduceId` 删除旧领料单（触发 `tri_deleteBillUseEntry` 级联删子表），再重建生产单三明细，最后在同一事务内生成领料单。多次保存不会累积重复领料单。
2. **领料单头（t_PMS_BillUse）**：每张 BOM 组生成一张，单号 `LLD`+8 位（`NextBillUseNo`/`NextBillUseInterId` 复用 `BillNoLock` 并发保护）；回写部门/车间/小组/领料人。
3. **信任边界（防前端篡改）**：
   - 产出品行（`IsProduct=1`）的领用数量**服务端拥有**（=计划量），前端回传值忽略；
   - 原材料行（`IsProduct=0`）的领用数量**信任前端回传**（`BuildPostedUseNumMap` 按 `BomId|ItemId|IsProduct` 建 FIFO 队列，`TakeUseNum` 取用）；
   - `ItemId / IsProduct / BomId / StepId` 一律服务端从 BOM 展开取，未知行直接拒绝。
4. **状态回写**：产品行 `FPickingStatus=1`、`FBillUseFInterID` 指向领料单；生产单 `FOrderStatus=1`、`FPickNo` 写入领料单号。

## 使用方式
新增/修改生产单：填基本信息与产品明细 → 填「领料信息」卡（部门/车间/小组/领料人）→ 在「原材料明细 / 产品结构」表末列「领用数量」按需调整原材料领用量 → 保存即同步生成领料单。
