# 上周开发进度梳理（2026-09-01 ~ 2026-09-06）

> 项目：GONES.Web — 旧 WinForms ERP 的绞杀者式 Web 迁移（.NET 9 + ASP.NET Core MVC + Furion + Tabler UI）

## 一、基础设施与框架（9/4）

- **EF6-on-.NET-Core 使能**：从 EDMX 抽取 CSDL/SSDL/MSL 为独立嵌入资源，连接串改由 `appsettings.json:ConnectionStrings:GonesErp` 传入 `new zsnewposEntities(connStr)`，绕开 ConfigurationManager；`Program.cs` 早期 `DbConfiguration.SetConfiguration` 注册 `System.Data.SqlClient`。
- **登录 + 左侧菜单**：Cookie 认证；管理员判定 `RoleID<=3`；`t_ERP_Menu` 建树，`MenuViewComponent` 在 `_Layout` 侧边栏渲染；`MenuService.WebRoutes` 字典做「旧窗体 ClassName → Web 路由」映射。
- **引入 Furion 4.9.9.79**：`CreateBuilder(args).Inject()` 必须在 `AddInject` 前；业务控制器加 `[Microsoft.AspNetCore.Mvc.NonValidation]` 跳过 Furion ModelState 短路；`MenuService` 实现 `ISingleton` 自动注册。
- **UI 改版 Tabler v1.4.0**：资源本地化到 `wwwroot/vendor/tabler`（内网不走 CDN）；品牌色 `--tblr-primary:#185fa5`；引入 bootstrap.bundle.min.js 修复 Modal 依赖。
- **用户表切换 + 密码重置**：登录表从 `t_Base_User` 切到 `t_ERP_UserInfo`（Account/PassWord(MD5)/UserName/RoleID/Status）；admin 密码重置为 `123`（`202cb962...`）。
- **环境坑解决**：本机 build/run 需注入 `APPDATA/LOCALAPPDATA/NUGET_PACKAGES`；Kestrel 监听 `http://localhost:5000`；登录字段 `UserName/Password`。

## 六、质量保障与运维（9/6）
